# Slay the Spire Android Save Editor
Save Editor for Slay the Spire for Android

JavaScript app that reads and edits the save files for your Android version of Slay the Spire. Editing saves requires root or Shizuku and a terminal app like aShell. 

Included are instructions for readying your save for editing.

Editable: Unlocks for Characters, Cards, Relics, Bosses, Compendium Entries. Stats for each Character. Ascension Level for each character. Beat the Game and Neow Bonus flags.

You can also just download or edit a fully unlocked, or a completely empty, save file set.

Download your edited saves as a zip, or automatically edit them via a generated shell command.

Try it out at http://dannyhand.us/sts/
