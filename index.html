Slay the Spire Android Save Editor

For Android (and desktop) progress files: character unlocks, ascension levels, card and relic unlocks, and compendium. Everything runs in your browser. Nothing is uploaded.

Android setup first. On newer Android versions the game's preferences folder is locked. Follow the Android unlock guide (steps 2 and 4) once so the files are yours. After that, this editor can read and write them through aShell.

1. Copy your files out of the game folder

Run this in aShell. It copies your preference files into Download/sts-prefs so the browser can open them.


      


      
2. Load them here

      

        
Select every STS… file in Download/sts-prefs
          (long-press to select several), or a .zip of them.

        

          
          
        

        
        
        
Or drop files here on desktop. Steam's files are in
          SlayTheSpire/preferences.

      


      
…or start without your files

      

        
        
      

      
Starting without your files resets the stats in any file you replace. Loading your own
        files keeps them.
